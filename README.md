Student Management System in C

A simple console-based Student Management System developed using C programming and file handling.

Features

- Add Student
- View All Students
- Search Student by Roll Number
- Update Student Details
- Delete Student Records

Technologies Used

- C Programming
- Structures
- File Handling
- Functions

Storage

Student records are stored in a binary file named "students.dat".

How to Run

1. Download or clone this repository.
2. Open "main.c" in a C compiler.
3. Compile and run the program.
